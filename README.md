# Lecorder

강의를 녹음하거나 미디어 파일을 가져와 원본 음성과 시간 위치가 있는 Markdown을 저장하는 로컬 우선 앱입니다. PDF·이미지 강의노트의 원문, 페이지별 해설, 개요와 용어집을 함께 관리합니다.

- 녹음·실시간 초안·최종 음성 변환과 LLM 검토
- 수정 제안 승인·거절과 승인 기록 보존
- AI 일시정지, 완료 요청 재사용과 작업 복구
- 전체 자료 검색, 음성·LLM 사용량, 백업과 사본 병합

실제 사용을 검증한 환경은 **Apple Silicon macOS**입니다. Windows·Linux의 자동 테스트는 통과하지만 네이티브 도구 배포·OCR·전체 실제 사용까지 보증하지 않습니다.

## 설치

Xcode Command Line Tools와 Homebrew를 준비하고 프로젝트 폴더에서 실행합니다.

```bash
xcode-select --install
bash scripts/setup.sh --dry-run
bash scripts/setup.sh
```

설치는 도구 확인 → Python·CMake 준비 → Python 패키지 설치 → 네이티브 도구 빌드 → 모델 다운로드·검증 순서입니다. Git은 Xcode Command Line Tools에 포함됩니다. pyenv가 있으면 Python 3.13 계열을 사용하고, 없으면 기존 Python 3.11 이상 또는 Homebrew Python을 사용합니다. 전역 Python 버전은 바꾸지 않습니다.

기존 빌드와 검증된 모델은 재사용합니다. 다운로드·체크섬 오류를 해결한 뒤 같은 명령으로 다시 실행할 수 있습니다. 설치 과정이 실행 중 AI 서버를 시작하지는 않습니다.

## 실행

새 설치에서 `.env`가 없다면 예제 파일을 복사합니다. 기존 설정을 덮어쓰지 마세요.

```bash
cp .env.example .env  # 새 설치에서만
./start.command
```

기본 주소는 `http://127.0.0.1:5055`입니다. 종료할 때는 실행 터미널에서 Ctrl+C를 누릅니다. 모델은 요청 시 로드하고 유휴 상태에서 해제합니다. 앱이 소유하지 않은 서버는 종료하지 않습니다.

설정에서 경로·음성 변환·LLM을 바꿀 수 있습니다. 저장 시 연결을 검증하고, 상단 안내의 **재시작**으로 적용합니다. 녹음·원음 업로드는 먼저 마치세요. 모델이나 설정이 바뀌어 재사용할 수 없는 중간 요청은 다시 처리할 수 있습니다.

## 자료와 설정

`.env.example`에 지원하는 설정과 단위를 범주별로 설명합니다. 출력 폴더의 원음·Markdown과 `web/data`의 DB·노트·복구 자료는 역할이 다릅니다. 전체 자료와 이력을 이동하려면 앱의 **백업 및 이동**을 사용하세요.

외부 제공자를 선택하면 음성 또는 노트·변환 텍스트가 해당 서버로 전송됩니다. API 비용은 제공자 정책을 따르며 취소 이후에도 과금될 수 있습니다. 키는 보안 저장소 또는 환경변수로 관리하고 백업·로그에 포함하지 않습니다.
