# 개발과 검증

## 변경 절차

관련 진입점·생산자·소비자를 함께 확인하고 재현부터 합니다. 기능별 자동 회귀를 실행한 뒤 실제 사용 흐름을 확인합니다. 파일 이동 시 가져오기·테스트 주입점·진단 스크립트·문서 경로를 함께 갱신하고 옛 경로용 재노출 모듈을 남기지 않습니다.

```bash
python3 scripts/test.py all
python3 scripts/doctor.py
```

Python 단위·통합·도구 테스트와 Node.js 프런트엔드 테스트를 실행합니다. 실제 모델 검증은 이 테스트와 별개입니다. 개발용 Node.js를 제품 실행이나 설치의 필수 의존성으로 만들지 않습니다.

## 실제 검증

```bash
python3 scripts/verify_transcription.py SAMPLE.wav --language ko --llm --report REPORT.json
python3 scripts/verify_runtime.py --help
python3 scripts/verify-live.py SAMPLE-16K-MONO.wav --language ko --final --report REPORT.json
```

테스트용 데이터·출력 폴더와 별도 모델 포트를 사용합니다. 음성은 원음 보존·내용·구간 시간·처리 시간·실패·취소를, 모델은 지연 로드·연속 재사용·유휴 해제·OFF/ON·앱 종료를 확인합니다. 노트는 실제 PDF·이미지로 해설→개요→용어집 게시까지 확인합니다. 모의 제공자 검증을 실제 API 검증으로 보고하지 않습니다.

Safari에서 주요 화면·키보드·좁은 화면·밝고 어두운 모드·진행·오류 상태를 확인합니다. 녹음·브라우저 복구·설정 저장 중 탭 전환과 취소·노트 뷰어·사용량·백업은 각자의 수명주기를 검증합니다. 출처 파일은 보존하고 실행하지 못한 항목을 명시합니다.

## 설정 변경

`runtime_config`의 카탈로그가 운영 설정의 기본값·자료형·범위·설명을 정의합니다. 설치 스크립트·예제·실행 코드가 같은 값을 사용하도록 합니다. `.env.example`은 카탈로그로 작성하며 실제 경로와 API 키를 넣지 않습니다.

경로·제공자·모델·자원·타임아웃은 운영 설정입니다. DB·백업·결과 형식, 상태 이름과 고정 용어집 계약은 환경변수가 아닙니다. 내부 상수를 노출할 때는 운영자가 바꿀 이유와 검증 가능한 범위를 먼저 정의합니다. 제거하거나 이름을 바꾸면 실제 `.env`의 유효한 값을 보존하면서 생산자·검증·문서를 함께 변경합니다.

## 버전과 마이그레이션

앱 버전, DB 스키마 번호, 결과 형식, 단계별 생성 정책, 백업 형식은 각각 다른 계약입니다. 선언은 `versions.py`에서 관리합니다.

- 구조 변경: 다음 번호의 SQL을 `migrations/`에 추가하고 스키마 번호를 올립니다. 이미 적용한 SQL은 수정하지 않습니다.
- 결과 계약 변경: 해당 결과 형식 번호와 필요한 데이터 변환을 추가합니다. 코덱은 알 수 없는 형식을 조용히 해석하지 않습니다.
- 프롬프트 변경: 영향을 받는 단계의 처리 정책을 올립니다. 관계없는 단계의 완료 기록은 무효화하지 않습니다.
- 백업 계약 변경: 명시적 내보내기 필드·검사·참조 재연결과 백업 형식을 함께 변경합니다.

시작 시 환경 잠금과 적용 이력·체크섬·`user_version`을 검증합니다. 업그레이드 전 SQLite 안전 사본을 만들고 트랜잭션 안에서 변경하며 실패하면 작업을 시작하지 않습니다. 미래 버전이나 이력 없는 구DB를 자동 변환하지 않습니다. 자동 다운그레이드는 제공하지 않으며 이전 앱과 해당 시점의 데이터 사본을 함께 사용합니다.

```bash
python3 scripts/data_admin.py status /DATA/lecorder.db
python3 scripts/data_admin.py init --data-dir /EMPTY/DATA --output-dir /EMPTY/OUTPUT
LECORDER_ENV_FILE=/EMPTY/DATA/environment.env ./start.command
```

환경 ID는 브라우저 조각·알림·작업 상태의 범위입니다. 다른 환경의 브라우저 자료를 자동 등록하거나 삭제하지 않습니다. 전체 사용자 백업과 마이그레이션 직전 DB 안전 사본은 목적이 다릅니다.

개발 과정의 실험 결과와 한계는 Git 제외 `memories/status.md`에 통합하고 샘플은 `memories/samples`에 보관합니다. 일회성 실험과 사용자 환경 전환 내역을 사용 가이드에 누적하지 않습니다.
