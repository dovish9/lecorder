전체 자료 검색과 사용량

상단 검색창에서 녹음 제목·최종 전사문, 노트 제목·원문·개요·해설·용어집을 검색합니다. 강의·자료 필터는 하단 녹음 도구 선택과 독립적입니다. 결과를 누르면 해당 시간 또는 페이지로 이동합니다. 검색창에서 방향키로 결과를 고르고 Enter로 열며, Escape나 바깥 클릭으로 닫습니다. 처음에는 색인을 준비할 수 있습니다.

AI 사용량은 오늘·7일·30일·전체 중 선택합니다. 음성 변환은 처리한 음성 시간, LLM은 입력·출력 토큰 합계와 요청 횟수를 표시합니다. 어느 영역을 눌러도 같은 상세 팝업이 열립니다. 상세에서는 일별 막대와 기간 내 누적 점선 그래프, 처리 시간·완료·취소·실패·모델별 사용량과 로컬·외부 API·사용자 서버별 요청 수를 확인합니다. 그래프의 일별·누적 값은 좌우 눈금을 각각 사용합니다. 재시도도 집계되며 미제공 수치는 0으로 추정하지 않습니다. 과거 기록은 일부만 포함되고 요금 계산은 제공하지 않습니다.

백업 및 이동

녹음·업로드를 마친 뒤 백업 만들기를 누르고 완료된 ZIP을 다운로드하세요. 원본·결과·강의 설정·작업 이력과 서버에 저장된 복구 자료를 담습니다. AI는 백업 중 잠시 멈추고 원래 상태로 돌아갑니다. 모델, 실행 환경, API 키와 브라우저에만 남은 녹음 조각은 포함하지 않습니다.

가져오기에서 ZIP을 선택하면 파일 검증과 자료 수·이름 충돌을 확인할 수 있습니다. 별도 사본으로 가져오기를 누르면 기존 자료를 유지하면서 추가합니다. 같은 이름에는 (2), (3)을 붙이며 동일 백업을 다시 가져와도 사본을 만듭니다. 현재 저장 위치와 AI 설정은 바꾸지 않습니다. 다른 컴퓨터에서 가져온 미완료 작업은 모델 파일이나 API 키 확인이 필요할 수 있습니다.

현재 지원 환경은 Apple Silicon macOS입니다. Windows의 경로·보안 저장소·파일 탐색 기반은 준비했지만, 네이티브 도구와 OCR 설치 및 전체 실제 동작 검증은 아직 필요합니다.

02처음 설치하기

macOS에서 Xcode Command Line Tools와 Homebrew를 준비한 후 프로젝트 폴더에서 실행합니다.

bash scripts/setup.sh --dry-run  # 설치 예정 내역만 확인
bash scripts/setup.sh
cp .env.example .env
./start.command

cp 명령은 새 설치에서만 사용하세요. 기존 .env를 덮어쓰면 저장 위치 설정이 사라질 수 있습니다. LECORDER_OUTPUT_DIR에 결과 저장 폴더를 지정합니다.

  1. [1/5] 필수 도구: Xcode Command Line Tools(Apple Git 포함)·Homebrew를 확인합니다. 없으면 설치 방법을 안내하고 종료합니다.
  2. [2/5] Python·Homebrew: pyenv가 있으면 Python 3.13을 재사용하거나 추가 설치합니다. pyenv가 없으면 기존 Python을 사용하고, Python이 없을 때만 Homebrew의 최신 안정 버전 python을 설치합니다. CMake는 누락 시 설치합니다.
  3. [3/5] 패키지: 선택한 Python에 패키지를 설치·검사합니다. 기존 Python은 3.11 이상이어야 합니다. 직접 설치가 제한된 환경은 프로젝트의 dependencies/python/site-packages에 설치합니다. 실행 시에도 설치에 사용한 Python을 사용합니다.
  4. [4/5] 빌드: Whisper → llama.cpp → Kiwi → Vision helper를 빌드합니다.
  5. [5/5] 모델: 음성·VAD·LLM·이미지 projector·Kiwi·토크나이저 데이터를 내려받고 체크섬과 필수 설치 상태를 확인합니다.

--dry-run은 설치·빌드·다운로드 없이 예정 내역만 표시합니다. 모델 유효성은 실제 설치에서 확인합니다. 최종 검사는 네이티브 도구의 도움말 명령을 실행해 라이브러리 로딩 오류와 비정상 종료도 확인합니다.

설치 과정에서는 AI 서버를 시작하지 않습니다. 실패 원인을 해결한 뒤 setup.sh를 다시 실행하면 기존 빌드와 검증된 모델을 재사용합니다. 기존 설정과 자료는 유지하며 체크섬이 다른 모델은 임의로 삭제하지 않습니다. 모델 다운로드에는 시간과 디스크 공간이 필요합니다.

모델만 준비하려면 python scripts/download-models.py, 필수 설치 상태를 검사하려면 python scripts/check-install.py를 실행하세요. 개별 재빌드는 scripts/build-whisper.sh, build-llama.sh, build-kiwi.sh, build-vision.sh를 사용합니다.

실행 화면은 http://127.0.0.1:5055입니다. 로컬 모델은 작업할 때 로드하므로 화면을 연 직후 대기 상태여도 정상입니다.

python scripts/doctor.py

진단은 도구 설치 상태만 확인하며 모델을 로드하지 않습니다. Windows 설치·런처는 아직 제공하지 않습니다.

03저장 위치와 AI

설정의 승인한 검토에서 승인한 수정의 전후 문맥, 발화 시작·끝, 모델과 승인 시각을 확인할 수 있습니다. 이 기능 적용 이후의 승인부터 기록하며 재검수 후에도 유지됩니다. 원본을 삭제하면 이력만으로 음성을 복구할 수는 없습니다.

사이드바의 설정에서 경로, 음성 변환, LLM을 설정합니다. 입력을 바꾸기만 하면 적용되지 않으며 저장해야 합니다.

경로

프로젝트와 오디오·Markdown 저장 폴더를 지정합니다. 저장 후 화면 상단 알림에서 재시작을 누르면 적용됩니다. 녹음과 원음 업로드는 먼저 마쳐야 합니다.

AI 처리 일시정지

대시보드의 AI 처리 스위치로 음성 전사·실시간 받아쓰기·LLM 작업을 함께 멈추고 다시 켤 수 있습니다. 완료된 구간은 유지하며 취소된 요청부터 재개합니다. 마이크 녹음·원음 업로드·저장은 계속됩니다. OFF 중 종료한 녹음의 최종 전사는 재개를 기다립니다.

실시간 초안은 OFF 구간을 생략하고 ON 시점부터 이어집니다. 최종 전사에는 전체 원음이 사용됩니다. 정지 시간은 처리 시간에서 제외하며 외부 API는 취소 후에도 과금될 수 있습니다. 앱 재시작 시에는 항상 ON입니다. 하단의 녹음 일시정지와 구분하세요.

실시간 초안

설정의 음성 변환 → 실시간 전사에서 로컬 모델 ID·모델 파일·VAD 모델 파일 경로를 지정할 수 있습니다. whisper.cpp와 호환되는 모델을 사용하며, 변경은 서버 재시작 후 적용됩니다. 녹음 중 보관함의 해당 녹음을 열면 실시간 전사 중 · 초안을 볼 수 있습니다. 기본 모델인 로컬 large-v3-turbo가 발화 뒤의 무음을 기준으로 처리하며, 길게 이어지는 발화는 최대 20초 구간으로 나눕니다. 위로 스크롤하면 자동 따라가기가 멈추며 최신 내용으로 버튼으로 돌아올 수 있습니다.

모델 준비나 초안 처리에 실패해도 원음 녹음은 계속됩니다. 초안이 늦어지면 오래된 미처리 구간은 생략하고 누락을 표시합니다. 녹음 종료 후에는 아래에서 선택한 제공자로 원음 전체를 다시 처리합니다. 초안은 최종 전사·검수 결과가 아니며 최종 처리 실패 시에도 초안으로 남습니다.

녹음 중에는 다른 로컬 전사·LLM 작업이 실시간 전사 종료를 기다립니다. 일시정지 중에도 이 예약은 유지됩니다. 브라우저를 닫거나 새로고침하면 실시간 녹음은 이어지지 않습니다. 저장된 원음 조각은 기존 복구 기능을 이용하세요.

음성 변환과 LLM

음성 전사 기본값은 로컬 whisper.cpp의 large-v3, LLM 기본값은 로컬 llama.cpp의 Qwen3.5-9B입니다. 서버 URL과 API 키는 서로 다른 설정입니다. 로컬 자동 관리는 키 없이 모델 파일과 실행 파일 경로를 사용합니다.

음성 전사는 OpenAI whisper-1, LLM은 OpenAI·Claude·Gemini 연결을 지원합니다. 제공자·모델·URL을 선택하고 필요한 키를 입력한 뒤 연결 확인 → 설정 저장을 누릅니다. 연결 확인은 합성 입력을 사용합니다. 사용자 지정 서버는 직접 켜야 하며 Lecorder가 종료하지 않습니다.

기본값으로 초기화는 해당 AI 영역만 로컬 기본값으로 되돌립니다. 저장 위치와 기존 결과, 보관된 키는 삭제하지 않습니다. 키를 없애려면 저장된 키 삭제를 사용하세요.

키는 macOS Keychain 또는 Windows Credential Manager에 보관합니다. 보안 저장소를 사용할 수 없으면 저장에 실패하며 평문 파일로 우회하지 않습니다. 설정 조회와 로그에는 키 원문을 표시하지 않습니다.

외부 전사에는 음성을, 외부 LLM에는 전사문과 선택한 강의노트 텍스트·이미지를 보냅니다. 유료 API일 수 있으며 요청 후 중단해도 이미 처리된 요청은 과금될 수 있습니다.

경로·음성 변환·LLM 설정을 저장하면 화면 상단에 재시작 알림이 표시됩니다. 재시작을 누르기 전까지 기존 설정을 사용하고, 재시작 후 미완료 작업은 변경한 AI 설정으로 복구합니다. 원음과 확정 결과를 보존하며 모델이 달라 재사용할 수 없는 중간 요청은 다시 계산할 수 있습니다. 자동 재시작에는 start.command 실행이 필요합니다.

05녹음·업로드·강의노트

녹음하기

  1. 하단 도구에서 강의를 선택합니다. 선택 안 함도 가능합니다.
  2. 녹음을 누르고 브라우저 마이크 권한을 허용합니다.
  3. 녹음 중에도 강의와 강의노트를 선택하거나 바꿀 수 있습니다. 강의를 바꾸면 자동 생성한 녹음 이름도 바뀝니다.
  4. 일시정지·계속을 사용할 수 있으며 종료하면 녹음 조각을 보존한 뒤 전사 대기열에 등록합니다.

기존 파일 가져오기

파일 가져오기에서 강의, 강의노트, 저장 이름과 파일을 지정합니다. MP4·WebM·WAV·MP3 등 지원 미디어를 처리합니다. 강의를 선택하지 않으면 인식 힌트는 비워두지만 LLM 검수는 실행합니다.

강의노트

강의 화면의 강의노트 추가로 PDF 또는 PNG·JPEG·HEIC를 등록합니다. 이미지 묶음은 순서를 조정할 수 있습니다. 합계 100MB·최대 500페이지를 지원하며 PPTX는 PDF로 내보내야 합니다.

노트 분석은 원문·용어 후보 추출 → 페이지별 해설·기호 추출 → 개요 → 용어집 생성 순서입니다. 선택한 노트의 분석이 예정되어 있으면 전사는 분석 완료까지 기다립니다. 분석 실패·중단을 해결한 뒤 전사를 다시 실행하세요.

  • 개요: 전체 개념과 주요 수식의 연결을 읽습니다.
  • 페이지별 해설: 왼쪽 원문 페이지와 오른쪽 해설을 비교합니다. 페이지 목록·이전/다음·확대/축소를 사용하고 각 영역을 따로 스크롤합니다.
  • 용어집: 최대 40개의 용어·기호에 의미, 읽는 말, 출처를 표시합니다. 읽는 말이 있으면 음성 인식에는 읽는 말만 사용하고, LLM 검수에서 문맥에 맞는 정식 표기로 수정 제안합니다. 읽는 말이 없으면 정식 표기를 힌트로 사용합니다. 출처 페이지를 누르면 해당 해설로 이동합니다.
  • 원문: 페이지 이미지와 추출 텍스트를 대조합니다. 추출 오류를 확인하는 용도입니다.

용어집 다시 생성은 원문·해설·개요를 재사용합니다. 생성 중에는 기존 확정 용어집이 유지되며 중단할 수 있습니다. 성공해도 기존 녹음의 용어집은 바뀌지 않습니다. 확인 필요인 용어는 기본 제외됩니다. 새 용어집의 읽는 말은 필요한 항목에 한국어 또는 영어 표현 하나만 저장합니다. 읽는 말은 관용적인 발음 제안으로 실제 강사의 발음을 확인한 정보는 아닙니다. 선택을 저장한 뒤 재생성을 실행하세요.

확인 필요는 중요한 수식·설명·판독 문제 또는 자동 검증 실패가 남았다는 뜻입니다. 새 분석에서는 필요한 내용을 짧게 표시하고, 기호 추출과 사소한 지적·수정 전 기록은 접힌 검증 메모 보기에 보관합니다. 이전 분석의 경고는 자동으로 재판정하지 않습니다. 원문을 확인하고 필요하면 강의노트 다시 분석 또는 상세 해설 요청을 사용하세요. 재분석은 페이지 이미지를 공유하므로 동일 이미지를 매번 복제하지 않습니다.

06전사·검수·작업 로그

사이드바 아래 대기열을 펼치면 진행 중인 작업의 단계와 대기 이유를 볼 수 있습니다.

  1. 변환·전사: 원본을 보존하고 PyAV로 16kHz 모노 WAV를 만들어 전사합니다. 긴 파일은 구간별로 처리하고 타임스탬프를 합칩니다.
  2. 품질 확인: 로컬 Whisper의 VAD·반복·저신뢰 구간을 필요한 범위에서 다시 확인합니다. 외부 전사에 Whisper 전용 옵션을 보내지 않습니다.
  3. 검수: LLM이 문단과 수정 후보를 생성합니다. 인식 힌트가 없어도 검수합니다.
  4. 저장: 결과와 기록을 반영합니다. 검수 실패가 원본 음성이나 이미 저장된 전사문을 삭제하지 않습니다.

로컬 Whisper와 LLM 추론은 동시에 실행하지 않으며 요청 경계에서 전사를 우선합니다. 문서 원문 추출은 별도로 진행할 수 있습니다. 로컬 모델은 연속 작업에서 재사용하고 기본 60초 유휴 후 해제합니다.

보관함에서 녹음을 고르고 ••• → 로그 확인을 누르면 시작·종료 시각, 제공자·모델, 각 단계와 재시도·실패·소요 시간을 확인합니다. 수정 후보가 없어도 실행 시간은 표시합니다. 제공하지 않는 지표는 임의로 만들지 않습니다.

보관함에는 작업 날짜 · 총 걸린 시간을 표시합니다. 총 시간은 단계별 실제 처리 시간을 합산하며 대기 시간은 제외합니다. 이전 기록에 측정값이 없으면 일부 정보가 없을 수 있습니다.

07수정 제안·다시 실행·중단

수정 제안 확인

보관함의 검토 필요 항목에서 들린 표현과 제안, 해당 문장과 근거를 비교하세요. 타임스탬프의 원음 듣기로 실제 발음을 확인한 뒤 승인하거나 거절합니다. 승인은 현재 전사문과 Markdown에만 반영합니다.

작업 메뉴

  • 이름 수정: 저장 이름을 바꿉니다.
  • 로그 확인: 단계별 실행 기록과 총 시간을 봅니다.
  • 다시 전사: 기존 음성을 유지하고 이름·강의·노트를 다시 지정합니다. 실패·중단 시 기존 결과를 보존합니다.
  • 다시 검수: 음성 전사를 반복하지 않고 기존 전사문을 최신 LLM 설정으로 검수합니다.

대기·실행 중 작업의 중단 버튼으로 전사나 검수를 멈출 수 있습니다. 이미 시작한 요청을 정리하는 동안 중단 처리 상태가 잠시 유지될 수 있습니다. 이전 결과는 실패·중단 때문에 사라지지 않습니다.

완료 알림은 신규 전사·다시 전사·다시 검수를 구분합니다. 브라우저 알림은 사이트 권한과 운영체제 알림 설정이 허용되어야 합니다. 검토할 녹음의 배지는 강의 선택과 보관함에도 합산됩니다.

08실패 처리와 복구

문제가 생겼을 때는 원본을 유지하고 필요한 단계만 다시 실행하세요.

  • 녹음 중 서버 연결 끊김: 녹음 조각을 브라우저 저장소에 보관합니다. 저장소도 실패했다는 안내가 나오면 메모리 복구본을 잃지 않도록 탭을 유지하세요.
  • 미완료 녹음: 앱을 다시 열어 복구 안내나 보관함의 미완료 항목을 확인합니다. 남은 조각을 서버에 전송한 뒤 전사합니다.
  • 전사 실패: 로그에서 서버·모델·입력 오류를 확인하고 다시 전사합니다.
  • LLM 검수 실패: 기존 음성·전사문은 유지됩니다. AI 설정을 확인한 뒤 다시 검수를 사용합니다.
  • 노트 분석 중 재시작: 저장한 페이지를 재사용해 작업을 복구합니다. 실패 상태와 확인 필요 항목은 원문과 대조하세요.

서버가 없거나 인증에 실패하면 다른 제공자로 자동 전환하지 않습니다. 일시적 제한의 재시도는 최대 1회입니다. 종료 시 앱이 실행한 모델만 정리하며 사용자 지정 서버는 종료하지 않습니다.

브라우저를 닫아도 서버에 접수된 전사·검수·수식 검증은 계속됩니다. 그러나 진행 중인 마이크 녹음은 브라우저가 필요합니다. 서버 자체를 종료하면 처리도 중단됩니다.

앱을 다시 시작하면 완료된 전사 요청·품질 확인·검수·노트 생성 응답을 재사용하여 미완료 요청부터 이어갑니다. 입력이나 모델·요청 설정이 바뀌면 일치하지 않는 응답은 재사용하지 않습니다. 사용자 취소와 이미 실패한 작업은 자동 재개하지 않습니다. 대시보드 복구 안내를 확인하고 닫을 수 있으며 작업 로그에는 이력이 남습니다.

연결이 끊기거나 응답 시간이 초과된 AI 요청은 최대 1회 재시도합니다. 원본·모델·키가 없으면 설정을 해결한 뒤 다시 실행하세요. 녹음 중 새로고침하면 기존 녹음을 종료하고, 다시 열린 화면에서 저장 확인된 조각은 중복 전송하지 않고 나머지를 복구합니다. 복구·저장이 끝난 뒤 새 녹음을 시작할 수 있습니다. 브라우저 종료 순간 아직 저장되지 않은 마지막 음성 조각은 유실될 수 있으므로, 가능한 한 종료 버튼으로 저장을 마친 뒤 새로고침하세요. 마이크 녹음은 자동 재개되지 않으며 잠자기·브라우저 종료 중 실제 수집하지 못한 음성은 복원할 수 없습니다. 실시간 초안 생략과 원음 수집 중단은 서로 다릅니다.

09트러블슈팅

모델이 준비되지 않음

시스템 설정에서 실행 파일·모델·projector 경로와 연결 확인 결과를 보세요. 포트 충돌 시 Lecorder는 다른 프로세스를 강제 종료하지 않습니다. 직접 실행한 서버라면 자동 관리 체크를 해제하고 올바른 URL을 설정하세요.

OCR·수식 오류

원문 탭에서 추출 텍스트를 대조하세요. 기본 macOS OCR은 Vision입니다. Windows에서 Vision을 사용할 수 없다는 오류는 명시적인 미지원 상태이며 다른 엔진으로 조용히 바꾸지 않습니다. Tesseract는 별도 설치·선택과 품질 확인이 필요합니다.

알림이 오지 않음

브라우저의 사이트 알림 허용과 macOS의 해당 브라우저 알림 설정, 집중 모드를 확인하세요. 접속 주소가 바뀌면 별도 사이트로 취급될 수 있습니다.

개발 검증

python scripts/test.py all
python scripts/doctor.py
python scripts/verify_transcription.py sample.wav --language ko --llm

모델 없는 자동 테스트와 실제 모델 검증은 구분합니다. 실제 전사 검증은 기본 18080·18081 포트와 임시 폴더를 사용하며 필요한 표본·모델이 없으면 실패합니다. Windows 네이티브 도구와 전체 실제 실행, 외부 제공자의 유료 API 호출은 별도로 검증해야 합니다.
