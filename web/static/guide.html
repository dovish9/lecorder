Lecorder 도움말녹음·음성 변환·강의노트 대시보드 열기

일치하는 도움말이 없습니다.

Lecorder 사용 안내

강의를 녹음하거나 파일을 가져오면 원본 음성과 타임스탬프가 있는 Markdown을 저장합니다. LLM이 문단을 정리하고 수정 후보를 제안하며, 강의노트에서는 용어집·개요·페이지별 해설을 볼 수 있습니다.

로컬 우선 대시보드와 로컬 AI 서버는 기본적으로 127.0.0.1에서만 통신합니다. 녹음, 음성 변환 결과, 강의 설정과 작업 이력은 사용자가 지정한 폴더와 로컬 SQLite에 남습니다.

설치와 실행

Lecorder는 강의 녹음·음성 변환·강의노트를 관리하는 로컬 앱입니다. 현재 실제 사용을 검증한 환경은 Apple Silicon macOS입니다.

처음 설치

Xcode Command Line Tools와 Homebrew를 준비한 뒤 프로젝트 폴더에서 실행합니다. 설치 도구가 Python 실행 환경과 필요한 로컬 도구·모델을 준비합니다.

xcode-select --install
bash scripts/setup.sh --dry-run
bash scripts/setup.sh

이미 설치되어 있다면 설치 과정을 반복할 필요가 없습니다. 다른 운영체제의 기반 코드는 있으나 네이티브 도구와 OCR의 전체 실제 검증은 아직 필요합니다.

실행과 종료

start.command를 열면 서버가 시작되고 브라우저에서 대시보드가 열립니다. 기본 주소는 http://127.0.0.1:5055입니다. 터미널을 유지한 채 사용하고, 종료할 때는 실행 터미널에서 Ctrl+C를 누릅니다.

브라우저 탭을 닫는 것과 앱 서버를 종료하는 것은 다릅니다. 모델은 요청이 있을 때 로드되며, 준비됨 표시는 항상 모델이 메모리에 올라와 있다는 뜻은 아닙니다.

화면과 자료 탐색

화면 구성

대시보드
전체 검색·AI 사용량·복구 안내·검토함·백업을 확인합니다.
강의
강의별 언어와 강의노트를 관리합니다.
보관함
녹음 원음·변환 결과·수정 제안·작업 기록을 확인합니다.
설정
경로·음성 변환·LLM·승인한 검토를 관리합니다.

전체 자료 검색

녹음 제목·최종 변환 텍스트와 강의노트의 제목·원문·해설·개요·용어집을 검색합니다. 실시간 초안과 로그는 검색하지 않습니다. 강의·자료 종류 필터는 하단 녹음 도구의 선택과 독립적입니다.

결과를 누르면 해당 시간 또는 노트 페이지로 이동하며 음성은 자동 재생하지 않습니다. 방향키로 결과를 이동하고 Escape로 메뉴나 결과를 닫습니다.

AI 사용량

음성 변환은 처리한 음성 시간, LLM은 제공된 입력·출력 토큰을 표시합니다. K·M·B는 각각 천·백만·십억 단위입니다. 요청 횟수에는 재시도도 포함하며 완료 결과 재사용은 새 요청으로 세지 않습니다.

상세보기는 기본 7일이며 음성 변환과 LLM의 기간을 각각 선택할 수 있습니다. 일별 막대와 기간 내 누적 점선은 각각의 눈금을 사용합니다. 미제공 지표는 0으로 추정하지 않으며 API 비용은 계산하지 않습니다.

강의와 강의노트

강의 만들기

강의 화면에서 이름을 입력해 추가하고 한국어·English·자동 감지 중 언어를 선택합니다. 강의를 지정하지 않으려면 선택 안 함을 사용합니다.

노트 등록과 분석

강의노트 추가에서 PDF 한 개 또는 이미지 여러 장을 등록합니다. 이미지 순서를 확인하고 등록하고 분석을 누릅니다. PPTX는 PDF로 내보내세요. 업로드 한도는 등록 화면에서 확인할 수 있습니다.

분석은 원문 추출 → 해설 생성 → 개요 → 용어집 순서입니다. 원문 탭은 PDF·이미지와 추출 텍스트를, 페이지별 해설은 해당 페이지의 학습 설명을 보여줍니다. 확인 필요 표시는 원문과 대조가 필요한 내용을 뜻하며, 모든 생성 결과가 정확하다는 보장은 아닙니다.

용어집과 인식 힌트

원문 후보와 페이지 해설의 기호를 근거로 최대 40개를 선별합니다. 정식 표기·짧은 의미·읽는 말·출처를 확인하고 포함 여부를 선택합니다. 읽는 말은 실제 강사의 발음을 확인한 기록이 아닙니다.

읽는 말이 있으면 음성 인식에는 읽는 말만 전달합니다. 검수에서는 문맥이 맞을 때 정식 표기로 수정 제안합니다. 확인 필요 항목은 기본 제외됩니다. 용어집 다시 생성은 저장된 원문과 해설을 재사용하며 기존 확정본은 성공할 때까지 유지합니다.

다시 분석과 제거

팝업 상단의 다시 분석·분석 중단·목록에서 제거를 사용합니다. 상세 해설 요청은 선택한 페이지에만 적용됩니다. 작업에 연결한 노트는 당시 스냅샷으로 고정되므로 이후 노트 변경이 과거 녹음의 검수 문맥을 바꾸지 않습니다.

녹음과 파일 가져오기

마이크 녹음

  1. 하단 녹음 도구에서 강의와 강의노트를 선택합니다.
  2. 녹음을 누르고 브라우저의 마이크 권한을 허용합니다.
  3. 필요하면 녹음 일시정지·계속을 사용합니다.
  4. 종료를 눌러 원음을 저장하고 음성 변환 대기열에 추가합니다.

녹음 중 강의 화면을 탐색해도 녹음 대상 강의는 유지됩니다. 녹음 대상은 하단 도구에서 확인하세요.

실시간 초안

녹음 중 보관함의 해당 항목을 열면 발화가 끝난 뒤 초안이 표시됩니다. 위로 스크롤하면 따라가기가 멈추고 최신 내용으로 버튼으로 돌아올 수 있습니다. 초안은 최종 결과와 다르며, 늦어진 구간이 생략되어도 원음은 최종 음성 변환에 사용됩니다.

브라우저를 새로고침하거나 닫으면 마이크 수집은 끝납니다. 저장된 조각의 복구는 작업 제어와 복구 항목을 확인하세요.

기존 파일

파일 가져오기에서 강의·강의노트·이름과 오디오 또는 동영상 파일을 지정합니다. 강의노트 없이도 처리할 수 있습니다. 선택한 노트의 분석이 대기 중이면 최종 음성 변환은 분석 완료를 기다립니다.

음성 변환과 검토

결과 확인

보관함에서 원음과 타임스탬프가 있는 Markdown을 확인합니다. 재생기의 시간 위치나 변환 텍스트의 타임스탬프를 눌러 원음을 들을 수 있습니다. 실시간 초안과 최종 결과는 구분해서 표시합니다.

수정 제안

LLM은 원래 표현·제안·근거를 제공합니다. 원음을 듣고 승인하거나 거절하세요. 승인하면 현재 변환 텍스트와 Markdown에 반영되며 원음과 발화 시간 위치는 보존됩니다.

설정의 승인한 검토에서 승인 내역을 열람할 수 있습니다. 이 기록은 승인 당시의 원래 표현·수정 표현·시작과 끝 시간·근거를 보존하는 자료입니다.

다시 실행

다시 음성 변환은 원음으로 새 결과를 생성합니다. 다시 검수는 음성 변환을 반복하지 않고 기존 텍스트를 검수합니다. 실패하거나 중단하면 기존 확정 결과는 보존합니다. 로그 확인에서 단계별 처리 시간과 요청 상태를 확인할 수 있습니다.

작업 제어와 복구

대기열과 중단

왼쪽 작업 현황과 대기열에서 현재 단계·대기 이유를 확인합니다. 사용자 중단은 자동 재개하지 않으며 원음과 기존 확정 결과를 보존합니다. 단순 대기와 처리 실패는 구분됩니다.

AI 처리 ON/OFF

대시보드 AI 처리를 끄면 실행 중인 AI 요청을 취소하고 다음 요청을 대기시킵니다. 마이크 녹음·원음 업로드·저장은 계속됩니다. 다시 켜면 완료 구간을 유지하고 취소된 요청부터 실행합니다. 외부 API는 취소 후에도 과금될 수 있습니다.

OFF 동안의 실시간 초안은 생략되고 ON 시점부터 다시 수집합니다. 원음은 최종 처리에 모두 사용됩니다. 앱을 재시작하면 AI 처리는 ON으로 시작합니다. 하단의 녹음 일시정지와는 다른 제어입니다.

잠자기와 재시작

완료된 AI 요청은 입력·설정이 같으면 재사용하며 미완료 요청부터 이어갑니다. 원본·모델·키가 없으면 복구 확인 필요 안내를 확인하세요. 다른 제공자로 자동 전환하지 않습니다.

브라우저 녹음 복구

남은 녹음 조각은 서버 수신 내역과 대조해 다시 전송합니다. 서버가 저장을 확인하기 전까지 브라우저 조각을 보존합니다. 같은 브라우저와 접속 주소로 다시 열어주세요. 브라우저 저장소를 지우면 미전송 조각은 사라질 수 있습니다. 마이크가 꺼진 동안 실제 수집하지 못한 음성은 복구할 수 없습니다.

저장 경로와 데이터

경로 설정

설정 → 경로에서 프로젝트와 결과 저장 폴더를 지정합니다. 녹음·업로드를 마친 뒤 저장하고 상단 안내에서 재시작을 누르면 적용됩니다.

자료가 저장되는 곳

프로젝트/
└── web/data/                 앱 내부 데이터
    ├── lecorder.db           강의·작업·사용량 기록
    ├── notes/                등록 원본·노트 결과
    ├── recordings/           녹음 조각·작업 파일
    └── transfers/            백업·가져오기 작업

결과 저장 폴더/
├── 녹음 이름.mp4             원본 음성 (실제 확장자 유지)
└── 녹음 이름.md              시간 위치가 있는 변환 결과

내부 데이터와 결과 폴더는 역할이 다릅니다. 음성과 Markdown만 복사해도 원본은 보관할 수 있지만 강의 연결·검토·사용량·작업 이력까지 옮기려면 백업 및 이동을 사용하세요. 실행 중 내부 DB나 작업 파일을 임의로 지우지 마세요.

AI 연결 설정

최종 음성 변환

설정 → 음성 변환에서 제공자·모델 ID·서버 URL을 지정합니다. 로컬 자동 관리를 사용하면 로컬 파일에서 서버 실행 파일·모델·VAD를 지정합니다. 외부 OpenAI 음성 변환은 구간 시간 위치를 제공하는 whisper-1을 지원합니다.

실시간 음성 변환

같은 화면의 실시간 설정은 별도 로컬 서버를 사용합니다. 자동 관리는 항상 켜져 있으며 서버 실행 파일은 최종 음성 변환과 공유합니다. 모델·VAD·서버 URL은 따로 지정합니다. 최종 처리·강의노트 분석과 병행하므로 동시에 모델을 실행하면 메모리 사용이 늘어납니다.

LLM

설정 → LLM에서 로컬 llama.cpp 또는 외부 OpenAI·Claude·Gemini를 선택합니다. 로컬 파일은 서버·모델·비전 projector를 지정합니다. 외부 연결에는 해당 제공자의 키가 필요하며 키는 보안 저장소 또는 환경변수로 관리됩니다.

저장과 적용

설정 저장을 누르면 연결과 필요한 모델 기능을 검증합니다. 탭을 옮겨도 검증은 계속되며 변경 취소를 누르면 진행 중인 검증도 취소합니다. 실패하면 기존 설정을 유지합니다. 성공 후 상단 재시작 안내로 적용하세요. 미완료 작업은 재시작 후 복구합니다.

기본값으로 초기화는 편집값을 기본값으로 되돌립니다. 적용하려면 설정 저장이 필요합니다. 사용자 지정 서버는 직접 실행해야 하며 앱이 종료하지 않습니다.

외부 전송과 고급 설정

외부 음성 제공자에는 음성을, 외부 LLM에는 변환 텍스트와 선택한 노트 텍스트·이미지를 전송합니다. 요금과 취소 과금은 제공자 정책을 따릅니다. 고급 자원 한도와 타임아웃은 .env.example의 범주별 설명을 참고하세요.

백업과 이동

백업 만들기

녹음과 원음 업로드를 마친 뒤 대시보드에서 백업 만들기를 누릅니다. 작업을 잠시 정리하고 DB와 파일의 일관된 사본을 만든 뒤 AI 처리 상태를 복원합니다. 완료되면 ZIP을 다운로드해 보관하세요.

강의·원본·결과·검토·작업·사용량·서버의 복구 자료를 포함합니다. 모델·Python 환경·API 키와 브라우저에만 남은 조각은 포함하지 않습니다.

가져오기

  1. 가져오기에서 Lecorder 백업 ZIP을 선택합니다.
  2. 검사 결과의 자료 수·충돌 이름·누락 사항을 확인합니다.
  3. 별도 사본으로 가져오기를 눌러 확정합니다.

기존 자료와 합치며 같은 이름은 (2), (3)으로 구분합니다. 동일 백업을 반복해서 가져와도 별도 사본이 생깁니다. 현재 경로와 AI 설정은 유지됩니다. 미완료 작업의 원본·모델·키 연결이 없으면 확인이 필요합니다.

검사 실패나 취소 시 기존 자료는 유지합니다. 지원하지 않는 백업은 안내 후 중단하며 자동 변환하지 않습니다.

문제 해결

앱이 시작되지 않을 때

실행 터미널의 마지막 오류를 확인하세요. 포트 사용 중이면 기존 앱을 종료합니다. 데이터 버전·이력 오류는 DB를 임의로 수정하지 말고 사용 중인 앱과 데이터 환경을 확인하세요.

모델 연결이나 로드 실패

설정에서 제공자·URL·키·로컬 파일 경로를 확인한 뒤 저장해 검증합니다. 다른 프로세스가 같은 포트를 쓰는 경우 앱은 이를 강제 종료하지 않습니다. 메모리가 부족하면 동시에 실행하는 모델과 다른 앱의 사용량을 확인하세요.

OCR와 수식

노트 원문 탭에서 추출 텍스트를 이미지와 대조하세요. 판독 오류가 있는 기호·숫자는 추측하지 말고 원문을 확인합니다. macOS 기본 OCR은 Vision이며 Tesseract는 별도 설치와 선택이 필요합니다.

녹음과 알림

마이크 권한과 선택한 입력 장치를 확인하세요. 연결이 끊겼으면 같은 브라우저에서 다시 열어 복구 안내를 확인합니다. 완료 알림이 보이지 않으면 브라우저 사이트 권한·macOS 알림·집중 모드를 확인하세요.

확인할 정보

문제가 발생한 작업의 로그, 단계, 오류 메시지와 재현 순서를 함께 확인합니다. 진단은 python3 scripts/doctor.py로 실행할 수 있습니다. 개발 구조와 검증 절차는 프로젝트의 개발 문서를 참고하세요.
